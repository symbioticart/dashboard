# Серия «van Gogh / клеточные автоматы»

Алгоритмическая живопись из данных Oura Ring. Один день владельца = одно полотно.
Форму и цвет порождает клеточный автомат, начальное состояние которого целиком
вычислено из ряда пульса за этот день.

Серия стоит **вне основной линии Symbiotic Art**: основная линия остаётся
grayscale (R=G=B), цвет живёт только здесь и работает как цитата — заимствованная
палитра мёртвого художника, наложенная на живые данные.

## Устройство

```
данные дня  →  посев решётки  →  правило автомата  →  поле направлений
            →  композиционная арматура  →  мазок  →  импасто
```

| Файл | Роль |
|---|---|
| `src/art/rng.js` | детерминированные хэши, PRNG, последовательность R2 |
| `src/art/metrics.js` | ответы Oura → параметры дня, персональные перцентили, молчащие дни |
| `src/art/automata.js` | три движка: циклический автомат, Грей — Скотт, life-подобные правила |
| `src/art/field.js` | состояние автомата → направление и энергия мазка |
| `src/art/composition.js` | горизонт, пустоты глубокого сна, разломы |
| `src/art/palettes.js` | четыре палитры, тональные кривые, пропорции холстов |
| `src/art/periods.js` | карта данных: сигнал → параметр правила и свойство кисти |
| `src/art/brush.js` | масляный мазок, щетина, буфер высоты и свет по нему |
| `src/art/paint.js` | оркестратор и провенанс |

## Карта данных

| Сигнал Oura | Что задаёт | Смысл |
|---|---|---|
| поминутный ряд HR | начальную конфигурацию решётки | день буквально засеян |
| HRV | режим правила: порядок ↔ турбулентность | нервная система как погода поля |
| пульс покоя | скорость и радиус взаимодействия | |
| глубокий сон | пустоты, куда волна не заходит | провал сознания как непрокрашенный массив |
| пробуждения, беспокойство | разломы поля, обрывы мазка | разрыв — событие, а не шум |
| эффективность сна | выбор life-подобного правила | связная ночь даёт связную форму |
| калории, тренировки | длину, толщину мазка и высоту слоя краски | усилие тела в толщине краски |
| температурное отклонение | сдвиг температуры палитры | земля ↔ кобальт |
| **отсутствие данных** | полотно окаменевает на грунте | отсутствие должно быть видно |

Все сигналы нормируются **персонально-перцентильно** по загруженному периоду:
значение само по себе ничего не значит, значимо только место в собственном
распределении владельца.

## Четыре пластических языка

| Период | Автомат | Источник |
|---|---|---|
| Нюэнен, 1883–85 | life-подобные правила с накоплением | «Едоки картофеля» |
| Арль и Сен-Реми, ночь, 1888–90 | циклический автомат (Griffeath, 1988) | «Звёздная ночь», «Дорога с кипарисом» |
| Овер-сюр-Уаз, 1890 | реакция-диффузия Грея — Скотта | «Пшеничное поле с воронами» |
| Смешанная система | язык выбирают данные дня | — |

Четвёртый вариант не имеет своего языка: он считает три оценки по данным дня
и объявляет выбор в провенансе. Тяжёлый землистый день уходит в Нюэнен, рваный —
в Овер, живой — в Сен-Реми.

## Детерминизм и провенанс

Во всём модуле `art/` нет ни одного `Math.random()`. Семя выводится из
`series/version/day/period`, всякая «случайность» — детерминированная функция от
данных дня. Одни и те же данные всегда дают побайтно одинаковое полотно; это
проверяется прогоном двух рендеров и сравнением пикселей.

Кнопка «Экспортировать провенанс .json» выгружает нормированные и сырые значения
дня вместе с параметрами всех четырёх правил — этого достаточно, чтобы полотно
было воспроизведено заново. Продаётся не файл, а правило.

## Практические заметки

- Стоимость письма растёт примерно как **куб** масштаба: число мазков идёт с
  площадью, а цена мазка — с его длиной и шириной в пикселях. Замеры в headless
  Chromium: 760px ≈ 1 с, 1400px ≈ 9 с, 2000px ≈ 23 с. Поэтому размеры экспорта
  объявлены явно, со временем ожидания.
- Клетка автомата должна быть **крупнее мазка**, иначе структура правила уходит
  под масштаб кисти и остаётся шумом. У каждого периода свой `gridWidth`.
- Поле нормируется **ранговой** нормировкой, а не растяжкой по min/max: у плотных
  правил почти все клетки жмутся к одному концу, и растяжка даёт одноцветный холст.
- Реакция-диффузия гаснет при F ≳ 0.030 — диапазон подобран прогоном так, чтобы
  никакие данные не могли убить поле.
